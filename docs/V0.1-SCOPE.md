# V0.1 — Core Foundation

## Goal

Establish a version-controlled, testable foundation for one custom AI Dungeon Scenario, compensating for a short (~4k-token) context window and a weak narrator model through explicit prompt contracts, compact dynamic context, and deterministic persistent state.

## Included

- Canonical Git repository and source-to-editor mapping.
- Pristine Scenario scripting baseline capture.
- Version-controlled AI Instructions, Plot Essentials, Author's Note, and Story Card templates.
- Scenario configuration baseline: Auto Summarization OFF, Memory Bank OFF, maximum available context, and no blank custom AI Instructions component.
- Prompt hierarchy, context-budget policy, and manual prompt deployment/checklist.
- Idempotent `state.rpg` initialization.
- Schema version 1 and safe root structure.
- Conservative validation/default merging and compatibility guard.
- Pure helper utilities and monotonic IDs/counters.
- Colon-command tokenizer/parser, `:help`, and minimal `:status` diagnostics.
- Compact Front Memory design contract; live injection implementation only after hook timing and size behaviour are verified.
- Deterministic and prompt-behaviour regression matrices.
- Live persistence, adventure isolation, undo/retry, prompt adherence, Story Card trigger, and Context Viewer verification.
- Rollback/release checklist for both source files and manually deployed prompt components.

## Excluded

- Book inscription interpretation and manifestation engine.
- AI-generated structured event protocol.
- Character progression rules and XP awards.
- Combat resolution.
- Inventory gameplay and item effects.
- NPC relationship/affection mechanics.
- Autonomous world simulation and quest system.
- Automatic authoring/updating of all Story Cards from runtime events.

## Exit criteria

- State initialization is idempotent and non-destructive.
- Current schema is identifiable and future versions are not silently downgraded.
- Helpers and parser pass deterministic tests.
- Static prompt components are in Git, installed in the Scenario, and pass the initial weak-model prompt regression tests.
- Scenario memory settings and actual context allocation are verified in Context Viewer.
- Compact Front Memory limits and hook timing are established empirically.
- Normal-turn persistence is verified in a disposable live adventure.
- Undo/retry behaviour is documented based on observation.
- The exact four editor script files and static prompt components are committed, tagged, and archived.
