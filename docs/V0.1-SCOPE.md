# V0.1 — Core Foundation

## Goal

Establish a version-controlled, testable script foundation that can safely own persistent RPG state.

## Included

- Canonical Git repository and source-to-editor mapping.
- Pristine editor baseline capture.
- Idempotent `state.rpg` initialization.
- Schema version 1 and safe root structure.
- Conservative validation/default merging.
- Explicit schema compatibility guard.
- Pure helper utilities.
- Monotonic IDs/counters.
- Colon-command tokenizer/parser.
- `:help` and minimal `:status` diagnostics.
- Regression test matrix, live persistence test, and rollback/release checklist.

## Excluded

- Book inscription interpretation and manifestation.
- AI-generated structured event protocol.
- Character progression rules and XP awards.
- Combat resolution.
- Inventory gameplay and item effects.
- NPC relationship/affection mechanics.
- Autonomous world simulation and quest system.

## Exit criteria

- State initialization is idempotent and non-destructive.
- Current schema is identifiable and future versions are not silently downgraded.
- Helpers and parser pass deterministic tests.
- Normal-turn persistence is verified in a disposable live adventure.
- Undo/retry behaviour is documented based on observation.
- The exact four editor files are committed, tagged and archived.
