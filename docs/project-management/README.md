# Project Management

`RPG-Task-Tracker-v0.1.xlsx` is the project control workbook. It contains the dashboard, V0.1 task backlog, change log, release register, test log, Git/rollback guidance, and architecture decisions.

Update status and evidence only after the acceptance check is actually performed. Draft files and written test plans do not count as live AI Dungeon test passes. Record the commit SHA for each logical source/prompt change.
